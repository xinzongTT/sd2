调用方式文档

1. 画布 / OpenAI 渠道配置

字段填写
协议OpenAI
接口地址https://sd2.3377777.xyz/v1（本页会自动填当前域名）
API Key在「API 密钥」页生成，如 sk-xxx
超时建议 600 秒（视频）
模型如 gpt_image_2、seedance_2_0_fast、text2image_soul_v2

2. 鉴权

Authorization: Bearer sk-你的密钥
# 或
X-API-Key: sk-你的密钥

3. 主要接口

方法路径说明
GET/v1/models模型列表
POST/v1/images/generations文生图 / 图生图
POST/v1/videos/generations文生视频 / 图生视频
POST/v1/generate统一生成（画布自定义节点）
POST/v1/files上传参考媒体 multipart file
GET/v1/jobs/{id}查询任务状态

4. 文生图示例

curl -X POST https://HOST/v1/images/generations \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt_image_2","prompt":"a red apple","size":"1024x1024","quality":"high"}'

5. 图生视频示例（Seedance Fast）

# 1) 上传参考图
curl -X POST https://HOST/v1/files \
  -H "Authorization: Bearer sk-xxx" \
  -F file=@./ref.png

# 2) 生成（start_image 用上传返回的 path）
curl -X POST https://HOST/v1/videos/generations \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"seedance_2_0_fast",
    "prompt":"gentle camera push-in",
    "size":"1280x720",
    "seconds":5,
    "start_image":"上传返回的path",
    "wait":true
  }'

6. 媒体字段

支持：image / image_references、start_image / end_image、video / video_references、audio / audio_references。
每个值可以是：本地 path、上传 id、http(s) URL、data URL、UUID。

7. 异步任务

wait:false 时立即返回 id，再用 GET /v1/jobs/{id} 轮询，直到 status=completed，取 url。

8. 注意

  • 本服务是 图片/视频 接口，不是 chat/completions 文本模型。
  • 账号 Token 过期需在「账号池」OAuth 重新登录；失效账号请删除后重加。
  • 管理台密码与 API Key 请部署后立即修改。
